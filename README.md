### 🚗 Real-Time Semantic Segmentation for Autonomous Navigation

Vision-based autonomous navigation system combining semantic segmentation with heading and speed control.

**Key Features:**

- Identifies roads, sidewalks, pedestrians, obstacles, and speed breakers
- Supports steering, speed adjustment, path following, and emergency stopping
- Achieved **99.28% Pixel Accuracy** and **95.61% Mean IoU**
- Demonstrates real-time scene understanding for robot navigation

**Tech Stack:**

```yaml
AI: PyTorch, Deep Learning, Semantic Segmentation
Vision: OpenCV, RGB Video Streams
Hardware: Intel RealSense D455
Application: Robotics, Autonomous Navigation
```

🔗 **Repo:** [Real-time-road-scene-Segmentation-controller](https://github.com/Amnafiaz200/Real-time-road-scene-Segmentation-controller)

### 🧠 Knowledge Distillation for Efficient Image Classification

Benchmarked knowledge distillation methods for lightweight CIFAR-100 image classification.

**Key Features:**

- Implemented Vanilla KD, Decoupled KD, and Evidential KD
- Used ResNet110 as teacher and ResNet20 as student
- Achieved **71.57% test accuracy** using DKD
- Performed hyperparameter tuning and teacher-student transfer analysis

**Tech Stack:**

```yaml
Language: Python
Framework: PyTorch
Models: ResNet110, ResNet20
Dataset: CIFAR-100
Methods: KD, DKD, EKD
```

🔗 **Repo:** [knowledge-distillation-cifar100-resnet](https://github.com/Amnafiaz200/knowledge-distillation-cifar100-resnet)
